# Seguridad

No publiques vulnerabilidades, credenciales, bases de datos ni proyectos reales en issues públicos.

Para reportar una vulnerabilidad de forma responsable, utiliza el formulario de contacto de [CodeAPU.cl](https://codeapu.cl/#contacto) e indica que el mensaje corresponde a **Seguridad de OpenAPU**. Incluye pasos de reproducción sin datos personales ni secretos.

Las versiones de desarrollo se entregan sin garantía. Antes de actualizar o probar cambios, crea un respaldo desde la aplicación.
