>_ OpenAPU

Comenzar es simple

No necesitas instalar Python, escribir comandos ni configurar el computador. Sigue estos tres pasos.

1

Extrae el archivo descargado

Haz clic derecho sobre OpenAPU-Windows.zip y elige Extraer todo. No abras OpenAPU dentro del ZIP.

2

Abre la carpeta extraída

Encontrarás esta guía, un único archivo de inicio y la carpeta interna Aplicacion. No necesitas modificar esa carpeta.

3

Haz doble clic para comenzar

Abre el siguiente archivo. OpenAPU iniciará y abrirá una pestaña en tu navegador.

INICIAR OPENAPU.cmd
Mientras usas OpenAPU: mantén abierta la ventana negra de inicio. Para terminar, ciérrala. Tus proyectos y presupuestos permanecen en tu computador.

¿Windows muestra una advertencia?

El paquete no instala un programa en Windows. Incluye el entorno oficial de Python que OpenAPU necesita. Si tu empresa restringe aplicaciones descargadas, consulta a su encargado informático.

¿No se abre?

Comprueba que primero elegiste Extraer todo. Si continúa, abre un reporte en GitHub sin adjuntar bases de datos ni antecedentes de proyectos.
