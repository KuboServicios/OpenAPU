# Contribuir a OpenAPU

Gracias por contribuir.

1. Abre un issue describiendo el problema o mejora.
2. Crea una rama desde `main`.
3. Mantén los cambios acotados y evita incluir bases de datos, exportaciones o información de proyectos.
4. Ejecuta `python -m compileall -q .` antes de enviar el cambio.
5. Abre un pull request explicando qué cambia y cómo se verificó.

Al contribuir aceptas que tu aporte se distribuya bajo la licencia AGPL-3.0-or-later del proyecto.
